# Mercedes Doctor M274 · 0.3

Автомобиль: Mercedes E200 W212, 2014, двигатель M274. Адаптер: ELM327 Bluetooth Classic, подключение к ранее сопряжённому устройству.

## Изменения

- Раздельные модули интерфейса, Bluetooth-обмена, OBD-парсера и записи поездок.
- Идентификация адаптера через ATI и протокола через ATDP; версия, заявленная адаптером, не подтверждает его подлинность.
- Проверка поддерживаемых PID по маскам 0100/0120/0140. Неизвестная поддержка отделена от отсутствующей.
- Единая очередь команд, тайм-ауты, закрытие сокета при потере синхронизации, ограниченное автоматическое восстановление по выбору пользователя.
- Десять стандартных параметров: обороты, ОЖ, воздух на впуске, MAP, дроссель, STFT/LTFT B1, напряжение ЭБУ, нагрузка и атмосферное давление. MAP обозначен как абсолютное давление.
- Панель с настраиваемыми виджетами, графики последних измерений с окном 30–180 секунд и min/max. Устаревшие значения скрываются.
- Mode 03 с учётом формата CAN; повреждённые и неоднозначные ответы не превращаются в показания или ложное «ошибок нет».
- Запись поездок на диск, 30 сессий, CSV со статусом каждого измерения, ZIP для ручной передачи в ChatGPT.
- В ZIP: vehicle.json, sensors.csv, dtc.json, elm_log.txt и session.json. Старые поездки v0.2 сохранены и экспортируются в исходном CSV.
- GitHub Actions собирает все Kotlin/Java-файлы и ресурсы, выполняет тесты и Android lint.

## Что проверено

Сборка debug APK: JDK 17, Gradle 8.9, Android SDK 35 / build-tools 35.0.0. Шесть JVM-тестов прошли без пропусков, в том числе 27 проверок OBD-протокола. Android lint: 0 ошибок и 0 предупреждений. Подпись APK проверена apksigner, версия пакета — 0.3 (код 3), Android 8.0+.

## Установка и первая проверка

Сохраните рабочий APK и экспортируйте важные поездки из старой версии. Это отладочная сборка с локальной debug-подписью: Android может не разрешить обновление поверх APK, подписанного другим ключом. Не удаляйте старое приложение до экспорта данных — удаление стирает его историю.

Установите APK, включите Bluetooth, сопрягите ELM327 в настройках Android и выберите его в приложении. Разрешите доступ к устройствам поблизости. Сначала проверьте подключение и показания на стоящем автомобиле; сопоставьте значения с известным диагностическим прибором. При проблемах экспортируйте журнал подключения.

Для полного отчёта остановите запись перед экспортом ZIP. Отчёт, экспортированный во время записи, помечен как незавершённый снимок. Укажите условия измерений при передаче ZIP на анализ.

## Границы версии

На телефоне, адаптере и автомобиле эта версия ещё не проверена. Фонового сервиса нет: при сворачивании приложения запись сохраняется, соединение закрывается. График — снимок; для обновления откройте его заново. Старые CSV доступны отдельно, расширенные ZIP создаются для новых поездок.

Расширенные параметры Mercedes/MED40, стоп-кадры, сравнение поездок и автоматическая аналитика пока не реализованы. Фирменные PID не угадываются. Многофреймовые и конфликтующие ответы нескольких ЭБУ отклоняются с сохранением исходного журнала. Отсутствие стандартных DTC не означает отсутствие фирменных ошибок Mercedes. Автоматического сброса ошибок, адаптаций, кодирования и управления исполнительными механизмами нет.

# Версия 0.4 — новая панель и release-подпись

Главный экран полностью переработан: круговой тахометр, отдельные карточки показаний и постоянная нижняя навигация «Панель / Поездки / Ошибки / ELM327». Версия **0.4** видна в правом верхнем углу. Вкладки разделяют живые измерения, запись/экспорт, DTC и настройки адаптера. Светлый список кнопок на присланном скриншоте относится к старой версии.

Добавлены тест запуска настоящей Activity и переключения вкладок, а также отрисовка экрана средствами Robolectric. Всего прошли 8 JVM-тестов (включая 27 проверок протокола); release Android lint — без замечаний. Отрисованный экран сохранён в downloads/dashboard-v0.4.png.

Файл downloads/MercedesDoctor-M274-v0.4-release.apk собран как release, режим отладки выключен. Подписи v2 и v3 проверены apksigner. Он подписан отдельным RSA 3072 ключом, а не временным debug-ключом GitHub. Приватный ключ хранится вне репозитория; для последующих обновлений нужен этот же ключ. Сделайте его защищённую резервную копию до удаления облачной среды. Файл APK доступен напрямую из публичной ветки без входа в GitHub.

Сохраните поездки из прежнего приложения перед заменой: новый сертификат может помешать установке поверх старой debug-сборки. Это не подтверждённый тест на реальном автомобиле; ограничения OBD-II и работы только при открытом приложении остаются прежними.
